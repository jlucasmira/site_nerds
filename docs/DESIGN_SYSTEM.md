# DESIGN SYSTEM

## Principios
- Dark-first com alto contraste.
- Glassmorphism para profundidade.
- Estetica high-tech sem comprometer legibilidade.

## Tokens Principais
- `--background`: `#101415`
- `--foreground`: `#e0e3e5`
- `--surface-container-highest`: `#323537`
- `--primary-container`: `#4b8eff`
- `--secondary-container`: `#00f1fe`

## Tipografia
- Familia principal: `Manrope`.
- Escalas:
  - Display: 64px
  - Headline: 32px
  - Body: 16px
  - Label: 12px

## Componentes
- `glass-panel`: fundo transluzido com blur e borda ciano suave.
- `text-gradient`: gradiente azul-ciano para destaque de termos-chave.
- `glow-accent`: brilho para elementos com prioridade visual.

## Responsividade
- Sidebar fixa no desktop.
- Drawer acionado por botao no mobile.
- Cartoes em grid com fallback para coluna unica em telas pequenas.
